# Quantum-Inspired Intelligent Traffic Route Optimization 🚦

Quantum-Inspired Intelligent Traffic Route Optimization is a Smart India Hackathon 2026 project by Team Sagraa187. It uses the Quantum-inspired Particle Swarm Optimization (QPSO) algorithm to find efficient vehicle routes based on traffic conditions, distance, travel time, and delivery constraints.

**Technologies:** Python, Flask, React, OpenStreetMap, Google Maps Routes API, and Firebase.

**Objectives:**
- Reduce traffic congestion and fuel consumption.
- Minimize travel time and transportation costs.
- Support multiple vehicles and delivery points.
- Improve route planning through intelligent optimization.
